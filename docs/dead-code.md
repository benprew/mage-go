# Dead Code Audit (2026-02-17)

Generated by merging coverage profiles from `go test -coverpkg=./...` across
both the engine and card test suites, then verifying each zero-coverage exported
function with a codebase-wide grep to confirm it has no callers.

## How to reproduce

```bash
go test -coverpkg=./... -coverprofile=/tmp/cover-engine.out .
go test -coverpkg=./... -coverprofile=/tmp/cover-cards.out ./cards/...
$(go env GOPATH)/bin/gocovmerge /tmp/cover-engine.out /tmp/cover-cards.out > /tmp/cover-merged.out
go tool cover -func=/tmp/cover-merged.out | awk '$NF == "0.0%"'
```

Then for each candidate, verify it has no callers outside its own definition:

```bash
grep -rn 'FunctionName' --include='*.go' .
```
